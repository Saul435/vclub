# Guía de Instalación y Ejecución del Proyecto Video Club

## Descripción General

Este proyecto está compuesto por dos partes:

- **Backend:** Flask + SQLite
- **Frontend:** React + Vite

La base de datos SQLite ya está incluida en el proyecto.

---

# 1. Requisitos Previos

## Instalar Python

Descargar Python desde:

https://www.python.org/downloads/

Verificar instalación:

```bash
python --version
```

o

```bash
py --version
```

---

## Instalar Node.js

Descargar la versión LTS desde:

https://nodejs.org

Verificar instalación:

```bash
node -v
npm -v
```

---

# 2. Extraer el Proyecto

Descomprimir el archivo ZIP.

La estructura debe verse similar a:

```text
vclub/
│
├── backend/
│   ├── app.py
│   ├── requirements.txt
│   └── ...
│
└── frontend/
    ├── package.json
    └── ...
```

---

# 3. Crear el Entorno Virtual del Backend

Abrir una terminal y ubicarse en la carpeta backend:

```bash
cd vclub/backend
```

## Crear entorno virtual

```bash
python -m venv venv
```

o

```bash
py -m venv venv
```

---

## Activar entorno virtual

### CMD

```cmd
venv\Scripts\activate
```

### PowerShell

```powershell
.\venv\Scripts\Activate.ps1
```

Si todo funciona correctamente aparecerá:

```text
(venv)
```

al inicio de la línea de comandos.

---

# 4. Instalar Dependencias del Backend

Instalar las dependencias definidas en requirements.txt:

```bash
pip install -r requirements.txt
```

Si ocurre algún problema con el archivo:

```bash
pip install Flask Flask-Cors Flask-SQLAlchemy SQLAlchemy
```

---

# 5. Ejecutar el Backend

Ubicado en:

```text
vclub/backend
```

ejecutar:

```bash
python app.py
```

Deberá aparecer algo similar a:

```text
* Running on http://127.0.0.1:5000
```

---

# 6. Verificar Funcionamiento del Backend

Abrir en el navegador:

```text
http://localhost:5000
```

Debería responder:

```json
{
  "message": "Sistema Video Club API funcionando"
}
```

---

# 7. Configurar el Frontend

Abrir una segunda terminal.

Entrar a la carpeta frontend:

```bash
cd vclub/frontend
```

---

# 8. Instalar Dependencias del Frontend

```bash
npm install
```

---

# 9. Verificar la Configuración de la API

Abrir el archivo:

```text
src/services/api.js
```

Verificar que la URL del backend sea:

```javascript
import axios from "axios";

export default axios.create({
  baseURL: "http://localhost:5000",
});
```

Si aparece otra dirección o puerto, actualizarla.

---

# 10. Ejecutar el Frontend

Desde la carpeta frontend ejecutar:

```bash
npm run dev
```

Deberá aparecer algo parecido a:

```text
VITE ready

Local: http://localhost:5173/
```

---

# 11. Abrir la Aplicación

Abrir en el navegador:

```text
http://localhost:5173
```

---

# 12. Cómo Iniciar el Sistema Cada Vez

## Terminal 1 (Backend)

```bash
cd backend

venv\Scripts\activate

python app.py
```

---

## Terminal 2 (Frontend)

```bash
cd frontend

npm run dev
```

---

# 13. Solución de Problemas

## Error de CORS

El proyecto ya incluye:

```python
from flask_cors import CORS

CORS(app)
```

Por lo tanto normalmente no debería presentar problemas de comunicación entre frontend y backend.

---

## Error: "No module named ..."

Instalar nuevamente las dependencias:

```bash
pip install -r requirements.txt
```

---

## Error: "npm command not found"

Verificar que Node.js esté correctamente instalado:

```bash
node -v
npm -v
```

---

- Descripción de artículos

# 16. Base de Datos

La base de datos SQLite se encuentra en:

```text
backend/instance/videoclub.db
```

Si este archivo existe, el sistema debería iniciar con los datos almacenados sin necesidad de crear tablas manualmente.

---

# Conclusión

Para ejecutar correctamente el proyecto Video Club:

1. Instalar Python y Node.js.
2. Crear y activar el entorno virtual.
3. Instalar dependencias del backend.
4. Ejecutar Flask.
5. Instalar dependencias del frontend.
6. Ejecutar React con Vite.
7. Acceder a la aplicación desde http://localhost:5173.
